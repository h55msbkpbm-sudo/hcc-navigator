# HK HCC Demographics Mapper

Interactive single-page tool for mapping unresectable HCC patient profiles against IMbrave150, HIMALAYA (STRIDE), and CheckMate 9DW trial baselines — with Chinese-population efficacy data.

**Educational discussion aid only. Not a prescription and not eligibility determination.**

Open `index.html` locally or deploy as a static site (Vercel / GitHub Pages).

## Flow
1. Disease extent (age, gender, tumour burden, MVI, EHS, etiology, cirrhosis, AFP)
2. Fitness (Child-Pugh, ECOG)
3. Safety & treatment goal (varices, EGD, CV factors, autoimmune, prior therapy, goal)
4. Profile checkpoint → trial baseline alignment

## Notes
- CV risk is multi-select (0 → low, 1 → moderate, ≥2 → high)
- Efficacy snapshot uses Chinese / regional subgroup data
